## 使用规则

1. 两版只能投一版，数字必须一致。
2. 不引用 `ai-learning/rag2` 的 240 条 / R@5 95% / MRR 0.856 / P95 88ms；
   Crossbar 的数字是 24 文档 / 72 查询、hybrid R@5 0.9722、MRR 0.9190、P95 77.7ms。
3. 不写“企业级”“通用平台”“精通”。写“本地工作台”“确定性闸门”“可复现”。
4. 3 分钟演示视频已程序化生成（179 秒，终端实录 + 实测数字），但不是真人出镜；
   3 个真实外部用户仍是 0 / 3，简历不写，面试如实说。
5. 第二个项目选 MCP Trust Bench，不选 TestWitness / Agent Blackbox / MCP Guard；理由见对应文档，
   不重新讨论。
