## 已经补上的 P0

### 1. 产品有结论了

`POST /v1/security/reviews` 返回 `block` / `fix` / `ship`，并给出原因、
阻断数、豁免数、扫描文件数和耗时。UI 首屏直接显示结论，不再让面试官自己猜。

### 2. 证据链能闭环

一次评审可以带 `run_id`。服务会读取同一条 run 的事件，计算模型轮次、
工具调用、Token、时长、禁用工具，再与策略预算对照。代码结论和行为结论
落在同一份报告里。

### 3. 独立基准，不再自己出题自己考

固定 DSVW 与 OWASP NodeGoat 的 commit，标签人工写入 manifest，扫描器不参与。
限定应用代码精确率 83.3%、召回率 71.4%；整仓库精确率 16.7%。
整仓库那个数字故意保留，因为它暴露了第三方压缩库、教程和测试脚本带来的噪声。

### 4. 新机器与 CI

`make bootstrap`、`make demo`、`make benchmark`、`make security`。
GitHub Actions 有 Python/Node/Rust 三套检查，安全 job 上传 SARIF。
wheel 已构建，`policy.yaml` 在包内，`tests/` 未进 wheel，console script 为
`crossbar-security`。

### 5. 风险豁免是组织流程，不是注释

豁免必须有 owner、理由、到期时间；过期和撤销不生效；每次评审记录
`waived_by` 与 `waived_until`。这是企业敢用的最低条件。

## 仍然不够的地方

### P0：没有 3 个真实用户

这是现在最大的短板，且无法靠代码补。README 已明确写“未完成”，没有编造。

**下一步**：找 3 个不用你讲解的人，只给他们 README 和 `make demo`，
记录他们在哪一步卡住、花了多久、提了什么。把原话和修复记录写进
`docs/verification/user-trials.md`。做不到就继续写“未完成”。

### P1：单点技术深度仍只有 8.0

规则引擎做了 Python AST 与轻量污点分析，但：

- DSVW 的 SQL 拼接（第 22 行）和路径穿越（第 29 行）没检出；
- 跨文件数据流、框架特定 sink、依赖漏洞都没有；
- 规则只有 31 条，离 Semgrep 这类工具很远。

**不要**吹“自研 SAST”。更诚实的定位是“确定性交付闸门”，并明确它可以
外接 Semgrep/CodeQL 作为第二引擎。真要提深度，应该做“同一份 policy 同时
约束代码与 Agent 行为”，这是别人少有的组合，而不是规则数量。

### P1：大仓库性能没有数据

当前只有小仓库扫描耗时。没有 10 万文件、Windows 路径、长路径、符号链接的
压测。面试官问“你们仓库 20 万文件要多久”，现在只能回答“没测”。

### P1：误报治理还粗糙

整仓库 25 个误报主要来自 `vendor/`、教程、示例证书、测试脚本。下一步应该做：

- 默认忽略 `vendor/`、`node_modules/`、`dist/`、教程目录；
- 规则级 allowlist，但必须带 owner 和到期时间；
- 对压缩文件跳过或只做哈希/密钥扫描；
- 公开误报下降曲线，而不是只报一次数字。

> 2026-11-16 更新：以上四项已落地。规则误报修复把整仓误报 25 -> 17，精确率
> 16.7% -> 22.7%；默认忽略目录再降到 3；带 owner 与到期时间的规则白名单降到 0，
> 精确率 100.0%，召回率保持 71.4%。明细见 `docs/verification/security-benchmark.md`。

### P2：UI 还没有真实截图/GIF

页面已经可用，但 README 首屏没有截图。3 分钟视频也没有录。
这两件事不影响正确性，直接影响转化率。

### P2：RAG 指标不要和 Crossbar 混写

`ai-learning/rag2` 的 240 条、R@5 95%、MRR 0.856、P95 88ms 不是 Crossbar 的
数字。Crossbar 自己的 RAG 基准是 24 文档 / 72 查询，hybrid R@5 0.9722。
简历只能引用后者，并且要写清“Crossbar 自带语料”。

## 如果只再做三件事

1. 找 3 个外部用户，按他们的卡点修，写 `user-trials.md`。
2. 录 3 分钟视频：`make demo` → UI 结论页 → SARIF → 豁免。
3. 做误报治理前后对比：同一基准，精确率从 16.7% 提到多少。

做完这三件，综合可以到 9.0；不做，8.4 就是当前真实上限。
